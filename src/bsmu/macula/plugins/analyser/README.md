# Модуль Analyser: структура и назначение

Модуль анализирует маски OCT-сетчатки и измеряет параметры (друзы, отслойки,
РПЭ, хориоидею, толщины сетчатки).

## Структура

### Данные и контракт

* `schema.py` — **единый источник правды**: классы сегментации, тексты
  локализаций, `MeasurementId`, `Parameter`, `RowKey`, спецификации отслоек
  (`DetachmentSpec`) и построители строк (`detachment_rows`, `drusen_rows`,
  `make_row`, `group_rows`). Строка результата — обычный `dict`, но имена
  ключей берутся отсюда, а не пишутся строками по коду.

### Геометрия и измерения

* `geometry.py` — сглаживание масок, верхняя граница хориоидеи, сплайны,
  нормали, поиск центра фовеолы.
* `curves.py` — измерения вдоль линии хориоидеи: ЦТС в фовеоле и рядом с
  фовеолой/фовеей, перпендикуляр через фовеолу, толщина хориоидеи в центре.
* `location.py` — локализация находок по зонам маски фовеа (приоритет
  фовеола → фовеа → макула и «порядочная» нумерация для СРЖ).
* `scale.py` — поиск L-объекта и расчёт масштаба (мкм/пиксель).
* `measurements/kernel.py` — общий алгоритм: границы объекта, ширина вдоль
  границы, максимальный перпендикуляр, фильтрация мелких компонент.
* `measurements/rpe.py` — состояние РПЭ, дефекты, толщина по скелету.
* `measurements/detachment.py` — отслойки ПЭ (классы 2, 10, 11, 16) и
  отслойка нейроэпителия (класс 6).
* `measurements/drusen.py` — измерение отдельных друз.
* `measurements/path_metrics.py` — пересчёт «чистой» длины пути в мкм.

### Анализ и интерфейс

* `analyzer.py` — `MaskAnalyser`: собирает строки измерений. `analyze()`
  состоит из небольших `_append`-методов по группам патологий.
* `plugin.py` — `MaskAnalyserPlugin`: пункт меню «Process Mask», чтение слоёв
  снимка, показ окна результатов.
* `highlight.py` — `HighlightRenderer`: подсветка объекта при наведении в
  таблице.
* `data_converter.py` — `PatientExamDataBuilder`: единственный проход
  «строки измерений → `PatientExamData`».
* `analyzed_table.py` — `TableWindow`, `ObjectsTableModel`,
  `DetachmentDetailModel`: только представление.

Старые фасады `analyzer_utils` и `mask_analyser` удалены: подключайте
конкретные модули (`analyzer`, `plugin`, `measurements.*` и т.д.).

## Поток данных

```
Слои снимка (images / masks / mask-fovea)
    ↓  MaskAnalyserPlugin._read_layers (приведение к ANALYSIS_SIZE)
MaskAnalyser.analyze()
    ├── extract_upper_boundary + smooth_boundary
    ├── curves / measurements.*                    (измерения)
    └── schema.detachment_rows / drusen_rows       (строки таблицы)
    ↓
PatientExamDataBuilder.build(rows)                 (PatientExamData)
TableWindow(rows, ...)                             (таблица результатов)
    └── HighlightRenderer.render(row, analyser)    (подсветка по наведению)
```

## Тесты

```
python -m unittest discover -s src/tests -t src
```

Тесты работают на синтетических масках (`src/tests/synthetic.py`), таблица
проверяется в offscreen-режиме Qt.

## Зоны фовеа (mask-fovea)

| Код | Зона |
|-----|------|
| 0 | фон / вне макулы |
| 1 | фовеола (центр) |
| 2 | фовеа (без фовеолы) |
| 3 | макула (без фовеа и фовеолы) |

## Классы сегментации

| Класс | Структура |
|-------|-----------|
| 3 | интраретинальная жидкость (ИРЖ, кистозный отек) |
| 4 | субретинальный гиперрефлективный материал (СРГМ) |
| 5 | интраретинальный гиперрефлективный материал (ИРГМ) |
| 6 | субретинальная жидкость / отслойка нейроэпителия (СРЖ) |
| 7 | жидкость под мембраной Бруха (SBF) |
| 9 | ретинальный пигментный эпителий (РПЭ) |
| 10, 11, 16, 2 | отслойки ПЭ: фиброваскулярная, друзеноидная, геморрагическая, серозная |
| 12 | эллипсоидная зона (EZ) |
| 13 | миоидная зона (MZ) |
| 14 | хориоидея |
