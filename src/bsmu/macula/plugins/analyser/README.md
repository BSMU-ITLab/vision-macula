# Модуль Analyser - структура и назначение

## Обзор
Модуль для анализа OCT-масок сетчатки и измерения параметров (друзы, отслойки, РПЭ, хориоид).

## Структура файлов

### `mask_analyser.py` (основной файл)
- **MaskAnalyserPlugin** - плагин для интеграции с Vision Framework
  - Регистрирует команду "Process Mask" в меню Algorithms
  - Управляет жизненным циклом анализатора
  
- **MaskAnalyser** - главный класс-координатор анализа
  - Использует ScaleCalculator для работы с масштабом
  - Использует DataConverter для конвертации результатов
  - Содержит основной метод `analyze()` для обработки масок
  - Измеряет толщины, друзы, отслойки, состояние РПЭ

### `scale_calculator.py`
**ScaleCalculator** - класс для калибровки и конвертации единиц измерения
- Хранит масштабы по X/Y (мкм/пиксель)
- Хранит данные о L-объекте для калибровки
- Методы:
  - `px_to_um_x()`, `px_to_um_y()`, `px_to_um()` - конвертация пикселей в микрометры
  - `calculate_distance_um()` - расчет расстояния с учетом масштаба
  - `is_calibrated` - проверка наличия масштаба

### `data_converter.py`
**DataConverter** - конвертация результатов в структуру PatientExamData
- Методы:
  - `to_patient_exam_data()` - основной метод преобразования
  - `_fill_thicknesses()` - заполнение толщин (хориоид, сетчатка)
  - `_fill_detachments()` - заполнение данных об отслойках
  - `_fill_drusen()` - заполнение данных о друзах
  - `get_zone_defects_location()` - определение локализации дефектов по зонам фовеа
  - `get_drusen_location()` - определение локализации друзы (алгоритм 0-3)

### `analyzer_utils.py`
Утилитарные функции для анализа:
- `extract_upper_boundary()` - извлечение верхней границы слоя
- `smooth_boundary()` - сглаживание границы
- `get_foveola_center()` - поиск центра фовеолы
- `central_width_of_retina()` - измерение ширины сетчатки
- `perpendicular_through_foveola()` - построение перпендикуляра
- `analyze_rpe()` - анализ состояния РПЭ
- `detect_rpe_defects()` - детекция дефектов РПЭ
- `measure_rpe_thickness()` - измерение толщины РПЭ
- `detect_and_measure_detachments()` - измерение отслоек
- `measure_drusen()` - измерение друз
- `find_L_in_image()` - поиск L-объекта для калибровки
- `calculate_scales_from_L()` - расчет масштабов из L-объекта
- `measure_choroid_thickness_at_center()` - толщина хориоида

### `analyzed_table.py`
UI компоненты для отображения результатов:
- **ObjectsTableModel** - модель данных таблицы с редактируемыми полями
- **TableWindow** - окно с таблицами результатов и кнопкой "Сохранить в БД"
- `group_measurements_data()` - группировка измерений для таблиц

## Поток данных

```
Входные данные (маски + изображение)
    ↓
MaskAnalyserPlugin._process_mask()
    ↓
MaskAnalyser.analyze()
    ├── ScaleCalculator - калибровка по L-объекту
    ├── analyzer_utils - измерения и анализ
    └── DataConverter.to_patient_exam_data() - конвертация результатов
    ↓
TableWindow - отображение + сохранение в БД
```

## Использование

```python
# Пример использования
mask_analyser = MaskAnalyser(image_pixels, mask_pixels, mask_fovea_pixels, classes)
results = mask_analyser.analyze()  # Список словарей с измерениями
patient_data = mask_analyser.to_patient_exam_data(results)  # PatientExamData объект
```

## Принципы рефакторинга

1. **Разделение ответственности** - каждый класс имеет четкую зону ответственности
2. **Делегирование** - MaskAnalyser делегирует задачи специализированным классам
3. **Обратная совместимость** - все старые методы сохранены через делегирование
4. **Модульность** - легко тестировать и поддерживать отдельные компоненты

## Конфигурация классов объектов

Классы определяются в конфигурации:
- **RPE** (id=9) - пигментный эпителий сетчатки
- **Choroid** (id=14) - хориоид
- **Serous PED** (id=2) - серозная отслойка
- **Hemorrhagic PED** (id=16) - геморрагическая отслойка  
- **Fibrovascular PED** (id=10) - фиброваскулярная отслойка
- **Drusenoid PED** (id=11) - друзеноидная отслойка
- **Neuroepithelial** (id=6) - нейроэпителиальная отслойка
- **Drusen** (название содержит "Drusen" или "друз")

## Зоны фовеа (mask-fovea)
- **0** - фон / вне макулы
- **1** - фовеола (центр)
- **2** - фовеа (без фовеолы)
- **3** - макула (без фовеа и фовеолы)
